# 彩灯工坊 · 骨架扎制与透光预览系统

面向自贡彩灯扎制工艺的浏览器端工具：从钢丝骨架放样、绸布蒙附、LED 布光，到透光仿真、夜景预览与下料单，全流程在浏览器内完成，数据存本机 IndexedDB，零后端、零云端。

## 启动

```bash
npm install
npm run dev        # 开发，默认 http://127.0.0.1:5180
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
```

首次进入「灯组列表」点 **载入三个测试灯组**，即可得到祥龙（约 14 米）、盛世荷花（直径 4.5 米）、花灯仕女（高 3.6 米）三套完整示例。

## 六大页面

| 页面 | 能力 |
| --- | --- |
| 灯组列表 | 按灯会项目管理灯组，灯组分段，运输尺寸超限提示 |
| 骨架编辑 | 节点拖拽、杆件连接、截面环放样（平行传输标架）、钢丝自重/挠度/焊点粗算 |
| 蒙布 | 材质库（颜色/厚度/透射率/散射）、放样贴布、杆间下垂、UV 手绘颜料（折减透光） |
| 灯光布置 | 点光源与灯带，功率/色温/光效/步进可调，灯珠数、灯带米数、总功率、总光通量实时统计 |
| 夜景预览 | 场地水面倒影、第一人称巡场（WASD）、热力图、照度探针（手算对账）、灯位自动建议 |
| 下料单 | 钢丝长度、焊点数、布料面积（含 8% 搭接）、灯带米数、功率、自重，可打印/导 PDF |

## 透光计算模型（核心）

CPU 精确求解与 GPU 实时着色器共用同一套光度学公式，保证「所见即所算」：

```
点光源发光强度  I = Φ / 4π                    (cd)
布面内入射照度  E = Σ I·cosθ / d²             (lux)
颜料折减透射率  τ' = τ · (1 - 颜料黑度)
出射照度        Et = τ' · (E + 环境照度)       (lux)
朗伯面亮度      L = Et · scatter / π          (cd/m²)
```

- **CPU 路径**（`src/core/optics.ts`）：逐布面三角采样、逐灯珠求和，输出每个采样点的完整贡献明细，供「照度探针」与纸面手算逐项对账。
- **GPU 路径**（`src/render/cloth_shader.ts`）：同公式的 GLSL 实现，灯珠超 160 颗时按空间网格聚类压缩（通量累加、位置通量加权），覆盖范围不丢。
- 手算验证：`npm run test:optics`，正入射、60° 斜入射、颜料折减、环境光、探针一致性共 11 项断言，误差为 0。

## 性能

布面与骨架按对象合批，drawCall 不随机体量增长。实测（headless SwiftShader 软件渲染，真机 GPU 显著更高）：

| 三角面 | drawCall | FPS（软件渲染） |
| --- | --- | --- |
| 3.6k | 12 | 39 |
| 83k | 13 | 30 |
| 164k | 14 | 23 |

## 测试

```bash
npm run test:optics   # 透光公式手算对账（纯 Node，无需浏览器）
npm run test:smoke    # CDP 端到端冒烟，需先起 preview 并开 9222 调试端口的 Chrome
npm run test:perf     # 渲染帧率/三角面/drawCall 采样
```

冒烟与性能测试通过 Chrome DevTools Protocol 驱动，无第三方测试框架依赖。

## 工程约定

- 间距 8pt 网格、字阶 14/15/16/18/22/28、中性 slate 色阶，主色仅用于关键操作，全部走 CSS 变量
- 图标统一线性 SVG，无 emoji 当图标
- 配置缺失直接暴露，不用 `||` 兜底默认值
- 文件名小写下划线，注释单行，函数优先简洁
